# 바탕

바탕은 내가 고른 노트에서 필요한 내용을 출처와 함께 찾아 주고, 그 내용을 개발·문서·도면 작업에 활용하도록 돕는 AI 스킬입니다.
기존 노트를 가져올 때는 원본을 그대로 두고 사본으로 작업합니다.

[변경 기록](RELEASE.ko.md)

## 시작하기

macOS ARM64에서 Codex CLI 또는 ChatGPT 앱으로 사용합니다.
노트는 [Obsidian](https://obsidian.md/download) 볼트에 보관합니다.

노트를 찾고 읽는 기본 조회 도구는 Python 표준 라이브러리로 실행되며, Graphify와 Archify는 필요하지 않습니다.
노트 사이의 관계를 정리할 때는 [Graphify](https://github.com/Graphify-Labs/graphify)(Python)가, 설명 그림을 만들 때는 [Archify](https://github.com/tt-a1i/archify)(Node.js)가 필요합니다.
없으면 사용하는 AI에게 설치를 도와 달라고 요청할 수 있습니다. 확인한 버전은 [Third-party notices](THIRD_PARTY.md)에 있습니다.

저장소를 클론하고 그 폴더에서 AI 도구를 엽니다.

```sh
git clone https://github.com/revoepko/batang.git
cd batang
```

다음과 같이 설치를 요청합니다.

```text
이 폴더의 AGENTS.md에 따라 바탕을 설치해 주세요.
```

AI가 작업할 프로젝트 폴더와 노트를 보관할 볼트를 확인하고, 정해지지 않았다면 물어봅니다. 두 폴더는 같지 않아도 됩니다.
기존 설정과 스킬 등록은 그대로 두고, 필요한 설정만 승인받아 추가합니다. 자세한 내용은 [Codex 안내](skills/batang/references/hosts/codex.md)를 참고하세요.

## 기존 노트로 시작하기

1. **사용할 노트를 고릅니다.**
   볼트나 폴더에서 바탕으로 쓸 노트를 AI에게 알려 주세요. 고르지 않은 노트는 가져오지 않습니다.

2. **사본을 가져옵니다.**
   바탕은 원본을 수정하지 않고 사본을 준비하며 출처를 기록합니다.
   형식이 지원되지 않거나 확인이 필요한 노트는 처리를 보류하고 그 사실을 알려 드립니다.

3. **사용 노트 목록에 등록합니다.**
   준비된 사본을 사용 노트 목록(예: `ACTIVE.md`)에 등록하고, 노트별로 등록됐는지 확인해 알려 드립니다. 사본 준비와 등록은 별도 단계입니다.
   일반 노트 검색은 이 목록에서 이번 작업에 고르고 읽기를 허용한 노트만 대상으로 합니다. 볼트 전체를 알아서 뒤지지 않습니다.

4. **질문합니다.**
   아래 [요청하기](#요청하기)처럼 바탕을 호출해 찾고 싶은 내용을 물어보세요.

이미 바탕 형식에 맞는 노트는 확인을 거쳐 바로 등록할 수 있습니다. 처음부터 시작한다면 빈 볼트를 준비해도 됩니다.
단계별 지원 범위는 [가져오기 안내](skills/batang/references/import.md)에 있습니다.

## 요청하기

- Codex CLI: 요청 앞에 `$batang`을 입력합니다.
- ChatGPT 앱: `@`를 입력하고 바탕 스킬을 선택합니다.

바탕은 호출한 작업과 그 후속 요청에만 적용됩니다. 다른 작업에는 자동으로 적용되지 않고, 기존 AI 규칙과 역할도 그대로 유지됩니다.

| 요청 예시 | 예상 결과 |
|---|---|
| “이 폴더의 노트를 바탕으로 가져와 주세요.” | 고른 노트의 사본을 가져오고 노트별 등록 결과를 알려 줍니다. |
| “이 노트들에서 캐시 전략에 관해 어떤 결정을 했는지 찾아서 비교해 주세요.” | 관련 노트를 비교해 결정 내용과 근거를 출처와 함께 알려 줍니다. 나중 결정이 이전 결정을 바꾼 경우와 서로 맞지 않는 경우를 구분합니다. |
| “이 노트들을 참고해서 결정 내용을 decision.md에 정리해 주세요. 출처도 남겨 주세요.” | 요청한 파일만 수정하고 참고한 출처를 연결합니다. |
| “이 노트들로 짧은 안내문과 작업 흐름 그림을 만들어 주세요.” | 고른 노트에 근거한 안내문과 그림을 만듭니다. |

바탕은 고른 노트를 근거로 답합니다. 자료가 서로 맞지 않거나 지금도 유효한지 확인하지 못하면 그 상태를 알려 드립니다. 관계도와 그림은 이해를 돕는 보조 자료입니다.

## 읽기와 저장

- 고른 노트와 허용한 출처만 읽습니다. 대화 내용을 자동으로 저장하지 않습니다.
- 저장을 요청하면 지정한 대상에만 반영하고, 기존 노트는 수정하기 전에 백업합니다.
- 가져온 사본은 Obsidian에서 편집할 수 있습니다. 바탕에서 계속 찾으려면 맨 위의 바탕 속성(frontmatter)은 형식을 유지해 주세요.
- 노트 사이의 관계는 요청할 때만 정리합니다. 링크가 있다고 관계로 확정하지 않으며, 관계가 없다는 결론도 나올 수 있습니다. 그림은 요청할 때만 만듭니다.

## 잘 안 될 때

- **찾는 내용이 안 나와요.** 그 노트가 사용 노트 목록에 있고, 이번 검색 대상으로 골랐고, 읽기를 허용했는지 확인하세요. 일반 노트 검색은 이 범위 밖을 자동으로 찾지 않습니다.
- **찾기 결과가 일부 빠졌어요.** 선택한 노트에 형식이나 접근 문제가 있으면 정상 결과와 함께 확인된 실패 경로와 이유가 표시될 수 있습니다. 일부 결과는 전체 검색 완료나 결과 부재가 아니므로 AI와 누락 내용을 확인하세요. 범위나 활성 목록 등 전체 오류는 해당 경로를 표시하지 않을 수 있습니다.
  지원하는 형식의 일반 Markdown 노트라면 사본으로 가져와 쓸 수 있지만, 이미 손상된 바탕 속성은 가져오기로 자동 복구되지 않습니다. 그 노트 없이 찾으려면 이번 검색 대상에서 빼면 됩니다.
