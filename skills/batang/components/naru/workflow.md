# 나루: 요청별 진입

현재 호스트가 자연어 요청의 의도·자료·범위·권한을 판단하고 기존 skill 등록 및 도구 경로를 사용한다. 별도 adapter·hook·분류기·모델 호출기는 없다.

- 설치·첫 사용에서 기존 자료 가져오기는 [가닥](../gadak/workflow.md)과 [가져오기 계약](../../references/import.md)을 따른다.
- 기존 지식이 필요한 질문은 [수풀](../supul/workflow.md)을 따라 명시 활성 원문과 대조에 필요한 허용 출처만 읽는다. 과거 자료·실행 기록·백업은 기본 검색 대상이 아니다.
- “정리해줘”는 대화 답변으로 충족할 수 있으면 먼저 답한다. “바탕” 언급만으로 저장 승인으로 해석하지 않는다. 단순 대화·번역·문장 수정에 저장 절차를 강제하지 않는다.
- 명시 반영·정정·취소는 선택 자료와 대상·범위가 명확하면 [수풀](../supul/workflow.md)을 따른다. 충분한 승인을 다시 묻지 않고 결과에 영향을 주는 미정만 확인한다.
- 개발·문서·도면은 [마디](../madi/workflow.md)와 관련 [실행 계약](../madi/references/workflow-contract.md)을 읽고 프로젝트 필수 기준과 독립 검토를 따른다. 새 run은 등록 skill과 내부 절차의 동일 고정 checkout 및 SHA256SUMS를 확인한다. 기존 run은 전환하지 않고 개발 승인을 지식 저장 승인으로 확대하지 않는다.
- 요청된 설명은 글로 답할 수 있다. 시각화를 요청하면 [보기](../supul/bogi/workflow.md)를 따른다. 지식 조회에는 마디를 강제하지 않는다.
