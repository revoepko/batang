# 문서 작업 지침

문서 생성·편집·검수·요청된 출력 확인에만 적용한다. 프로젝트 계약과 사용자 승인 범위를 대체하거나 새 역할·권한·런타임을 만들지 않는다.

1. 편집 전 원본·대상 범위·보존할 목차, 제목, 표, 인용, 참조를 확인한다. 요청 범위 밖의 구조를 바꾸지 않는다.
2. 확정 사실, 가정, 미검증과 제안을 구분한다. 정적 문서 정합성은 실제 제품·인프라·배포 성공의 증거가 아니다.
3. Obsidian vault의 기존 폴더, 노트, frontmatter, `.obsidian`은 보존한다. 활성 목록의 형식·경로·포함 파일을 확인한 뒤에만 사용한다. 목록 부재·충돌은 승인 전 생성·덮어쓰지 않는다.
4. 저장, 저장본 재열기, PDF·공유·출력 가독성은 각각 별도 관찰이다. 관찰하지 못했으면 미검증으로 남긴다.

도구 선택은 해당 도구의 허용 범위만 뜻한다. 외부 전송·공유·게시·권한 확대를 자동 허용하지 않는다.
