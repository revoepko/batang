# 사용자 검토 표시 지침

검토 또는 승인이 필요한 대화에는 목표와 현재 단계, 실질 변경·영향·상태, 선택 이유, 위험·미정·미검증, 현재 권한과 필요한 결정을 표시한다. 상세 자료가 있으면 항목별로 현재 파일·근거 위치를 연결한다.

기존 승인 범위를 다시 승인받지 않는다. 다만 이번 승인 범위와 별도 결정이 필요한 항목을 구분한다. 실제 vault 생성, 목록 생성·변경, 외부 공유·게시, provider·권한 확대, GitHub 작업은 명시 승인 없이는 진행하지 않는다.

실제 설치·호스트 동작·Graphify 갱신·Archify 출력·rollback을 관찰하지 못했으면 문서나 정적 검사 통과로 완료라고 말하지 않는다. `PLAN_READY`, `TASK_DONE`, `RELEASE_READY` 및 `PASS`는 관찰 범위와 근거를 함께 제시한다.
