# 수풀: 지식 작업

호스트는 `active_index`가 명시하는 root 안의 Markdown과 요청에 필요한 허용 출처만 대상으로 한다. 하위 폴더 이름은 강제하지 않는다. 중복·잘못된 경로·파일 부재는 해당 항목을 유보하고 알린다. [두레](../dure/workflow.md)의 권한 범위와 [갈피](galpi/workflow.md)의 원문 계약을 확인한다.

선택한 기존 자료의 최초 복제는 [가져오기 계약](../../references/import.md)을 따른다. 일반 원문 읽기와 엄격한 관리 문서 파싱을 혼동하지 않는다.

조회·지식 검토·명시 범위 감사는 기본 읽기 전용이다. 조회 결과 저장, frontmatter 갱신, reflect, 재색인, 기본 보고서 생성은 하지 않는다. Markdown 한 벌이 원본이며 [고리](gori/workflow.md)의 Graphify 관계는 재생성 가능한 보조물이다. 관계를 단서로 현재 원문에서 출처·시점·조건·대상을 확인한다. 그래프가 없거나 stale·불완전하면 현재 Markdown으로 답하고 상태를 알린다. 같은 주제의 다른 내용은 재검토 계기이며 최신 저장본을 자동 승자로 정하지 않는다. 원문을 읽지 못했으면 미확인으로 남기고 근거를 넘는 확신을 표현하지 않는다.

선택 반영·정정·취소는 명시 대상과 승인 범위를 확인하고 갈피와 두레를 따른다. 원문 전문·전체 대화·별도 Raw+Wiki·DB 사본을 기본 저장하지 않으며 비밀번호·토큰·개인정보를 저장·로그로 남기지 않는다. 이동·이름 변경은 `batang_id`를 유지하고 새 경로 검증 후 활성 목록에 반영한다. 새 파일의 동일 ID·내용을 확인한 뒤 명시적으로 허용된 이전 파일만 기대 hash 대조 후 제거한다. 파일 부재만으로 삭제를 단정하지 않는다. 취소·삭제는 명시 대상만 처리하고 공유 원문·근거·legacy 자료는 함께 삭제하지 않는다.

선택한 노트의 등록은 저장·활성 목록 반영 뒤 승인된 범위의 고리 갱신과 재확인까지 포함한다. 관계가 없는 노트도 문서 노드와 ID·현재 hash가 대응하는지 확인한다. 그래프 게시 전 실패 시 이전 그래프를 유지하고 노트 조회는 허용하며 반영 대기로 알린다. 게시 후 재확인 실패는 결과를 단정하지 않고 현재 그래프와 보존된 백업을 대조한다. 다음 관련 요청에서 기존 등록과 현재 원문·그래프 hash를 대조해 같은 승인 범위에서 재개한다. 읽기 전용 요청·권한 변경·원문 충돌 시 쓰기를 보류한다. 이미 활성화된 노트의 외부 편집은 다음 관련 요청에서 hash 차이로 확인한다. 활성 목록 밖에 새 파일을 넣은 것만으로 자동 발견하거나 등록하지 않는다. 저장 성공과 그래프 반영은 따로 보고하며 여러 파일의 원자적 트랜잭션을 주장하지 않는다. 요청된 설명·시각화는 [보기](bogi/workflow.md)를 따른다. 결과는 확인 사실·판단·미확인과 필요한 원본 경로·위치를 구분한다. 실제 저장·검색·검사·설치·배포는 수행한 범위로만 보고한다. 설치 링크·기존 도구·DB·run을 자동 변경하지 않는다.
