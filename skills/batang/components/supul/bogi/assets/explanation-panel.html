본문으로 바로가기

네 가지 설명 방식

구조는 연결을, 절차는 순서를, 분기는 조건을, 비교는 선택 기준을 보여 줍니다.

네 사례는 설명을 위해 만든 가상 예제입니다. 실제 기관의 규칙·운영 현황·검증 결과를 뜻하지 않습니다.
01 / 구조

도서관은 사람과 자료를 연결합니다.

동네 도서관에서 이용자는 필요한 활동을 제안하고, 운영 모임은 공간과 자료를 조정합니다. 자원활동가는 정해진 운영 범위에서 이를 돕습니다.

핵심 관계

  • 이용자 → 운영 모임: 활동 제안
  • 운영 모임 → 공간·자료: 일정과 이용 기준 조정
  • 자원활동가 → 이용자: 안내와 정리 지원

조건

운영 모임은 공간과 자료를 확인한 뒤 활동을 확정합니다. 제안 접수만으로 이용 일정이 확보되지는 않습니다.

예외

공간이 이미 예약되었다면 대체 일정을 협의합니다. 자원활동가는 대출 기준을 임의로 바꾸거나 운영 모임의 결정 권한을 대신할 수 없습니다.

이 구조는 구성과 책임을 설명합니다. 모든 활동이 차례로 거치는 고정 업무 절차는 아닙니다.

02 / 절차

수리 접수와 일정 확정은 다른 단계입니다.

수리 공방은 접수 내용을 검토하고 부품과 작업 시간을 확인한 뒤 고객과 일정을 확정합니다. 완료 안내는 실제 수리와 점검이 끝난 뒤 보냅니다.

진행 순서와 완료 조건

  1. 접수: 증상과 연락 방법 확인
  2. 검토: 작업 가능 여부와 필요한 부품·시간 확인
  3. 일정 확정: 고객과 작업 날짜 합의
  4. 완료: 실제 수리·점검 결과 확인 후 안내

선행 조건

필요한 부품과 시간이 확인되고 고객이 일정에 동의해야 수리를 시작합니다. 접수 번호는 완료나 예약 확정의 증거가 아닙니다.

예외

부품이 없으면 대기 상태와 다음 확인 시점을 안내합니다. 수리가 불가능하면 이유를 설명하고 일정 확정 단계로 넘어가지 않습니다.

대기나 불가 상태는 완료로 표시하지 않습니다. 일정을 바꿔야 하면 바뀐 조건을 알리고 고객과 다시 합의합니다.

03 / 분기

경로는 조건에 따라 하나를 고릅니다.

공원 전체가 열려 있는지 먼저 확인합니다. 비가 오지 않으면 중앙길을, 비가 오면 지붕이 있는 회랑을 선택하되, 해당 경로가 닫혀 있으면 산책을 미룹니다.

조건별 결과

  • 공원 전체 폐쇄 → 산책 미루기
  • 비 없음 + 중앙길 개방 → 중앙길
  • 비 있음 + 회랑 개방 → 회랑
  • 선택할 경로 폐쇄 → 산책 미루기

판단 순서

전체 개방 여부를 먼저 확인하고 날씨에 맞는 경로의 개방 여부를 확인합니다. 전체 폐쇄 조건을 가장 먼저 적용합니다.

예외·미확인

날씨나 개방 상태를 확인하지 못했다면 경로를 확정하지 않습니다. 선택한 경로가 닫혀 있으면 다른 경로로 자동 변경하지 않습니다.

중앙길과 회랑은 조건별 대안이며 두 경로를 연속 이동하는 단계가 아닙니다. 실제 방문 전에는 해당 공원의 현재 안내를 확인해야 합니다.

04 / 비교

학습 시간뿐 아니라 지속할 조건을 비교합니다.

학습 모임은 한 주의 복습을 목표로 두 계획을 비교합니다. 짧게 자주 할지 길게 묶어 할지는 확보할 수 있는 시간과 과제 성격에 따라 달라집니다.

계획 A · 짧게 나누기

25분 × 주 5회 = 125분

매일 짧은 시간을 낼 수 있을 때 선택합니다. 시작과 정리를 여러 번 해야 합니다.

계획 B · 길게 묶기

60분 × 주 2회 = 120분

긴 시간을 따로 확보할 수 있을 때 선택합니다. 한 번을 빠지면 그 주 계획의 절반이 비게 됩니다.

공통 기준

주당 시간·참여 빈도·확보 가능한 연속 시간·빠졌을 때의 영향을 같은 기준으로 비교합니다.

선택 조건

짧은 틈은 자주 있지만 긴 시간이 어렵다면 A를, 긴 시간을 주 2회 확보할 수 있다면 B를 검토합니다. 총시간은 5분 차이이며, 횟수와 연속 시간도 다릅니다.

예외·한계

60분 이상 이어 해야 하는 과제에는 둘 다 맞지 않을 수 있습니다. 총시간만 비슷하다고 같은 경험으로 보거나 우수한 계획을 고를 수는 없습니다.

선택 전에는 참여자의 일정과 과제 조건을 확인해야 합니다. 이해도·성적·완주율을 관측한 자료가 없으므로 학습 효과의 차이는 미확인입니다.
