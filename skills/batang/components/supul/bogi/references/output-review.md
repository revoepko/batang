# 보기 결과물 검수

- [공통 표현 지침](../../../madi/references/clear-language.md)으로 본문을 검수했는가?
- 설명 대상의 핵심 구성·관계·조건·예외와 근거가 보존되는가? 정보 깊이가 주제에 맞으며 필수 내용이 숨겨지지 않는가?
- 구조·절차·분기·비교의 해당 내용이 각각 구성과 관계, 순서와 선행 조건, 조건별 결과, 공통점·차이·선택 기준을 전달하는가?
- JavaScript나 모션 없이도 핵심 상세에 접근할 수 있는가? 키보드·터치·reduced motion과 모바일·데스크톱에서 조작할 수 있는가?
- 필수 조건·예외·비교가 숨겨지지 않는가? 짧은 보충은 노출된 문장으로 쓰고 details나 팝업은 분량과 탐색에 필요한 경우에만 사용했는가?
- 시간 변화 자체를 설명하는 예외적 모션이 있다면 유한하게 실행되고 정지·다시 보기가 가능한가? 비활성·화면 밖·reduced motion 변경 시 중단하며 자동 재개하지 않는가?
- 예외적 모션을 사용하는 경우 정지 후 활동 중인 모션이나 반복 작업이 없는가? 성능 실측을 DOM·정적 검사와 구분해 기록한다. 실제 터치 시험과 viewport 크기 검증도 구분한다.
- 각 항목을 선택하면 필수 조건과 예외가 해당 패널 본문에 바로 표시되는가? DOM과 화면에서 버튼 묶음과 패널 사이에 다른 블록이 없고 항목별 조건이 패널 밖에 반복되지 않는가? JavaScript 없이도 각 항목의 본문과 조건을 읽을 수 있는가?
- 초안 고정 후 독립 검토, finding 수정과 재검토, 필수 검증을 완료했는가? 초안 인계를 완료로 판단하지 않았는가?
- PC 1280·모바일 320/390에서 같은 콘텐츠가 보이고 반복 선택 시 패널이 하나만 유지되며 스크롤을 강제하지 않는가?
- 실제 터치와 사람 이해도 비교는 배포 필수가 아니며 실행했다면 별도로 기록한다.
- 게시가 승인된 경우 사용자가 폐기·재생성 등 변경을 명시하지 않았다면 기존 주소와 접근 범위를 보존했는가? 폐기·재생성을 포함한 게시에서 검토한 HTML과 게시 결과가 일치하는가? 제작과 게시 결과를 별도로 기록했는가?

검토는 실제 대상과 환경을 확인한 범위에서 결과를 기록한다. 문서나 예제의 존재만으로 검증 성공을 뜻하지 않으며 미실행을 `PASS`로 기록하지 않는다.
